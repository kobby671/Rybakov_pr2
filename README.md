
# Практическая работа №2

## Тема
CSS, адаптивная вёрстка и SCSS. Организация стилей.

## Цель работы
Создать адаптивный каталог товаров с использованием
HTML, CSS Grid, Flexbox и SCSS.

## Используемые технологии
- HTML5 — структура страницы
- CSS3 — оформление сайта
- SCSS — организация стилей
- JavaScript — обработка данных и фильтрация
- Git — контроль версий

## Исходные данные
- dataset/catalog.csv — данные товаров
- dataset/theme.json — настройки оформления
- dataset/assets/ — изображения товаров
