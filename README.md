# Практическая работа №2

**Тема:** CSS, адаптивная вёрстка и SCSS. Организация стилей.  
**Проект:** адаптивный каталог учебных товаров.

## Технологии
HTML5, CSS Grid, Flexbox, SCSS (Dart Sass), JavaScript, Git.

## Исходные данные
- `dataset/catalog.csv` — 18 товаров с полями `id`, `name`, `category`, `price`, `rating`.
- `dataset/theme.json` — исходная палитра и размеры. Значения перенесены в `scss/_variables.scss`.
- `dataset/assets/product-01.svg` — `product-03.svg` — изображения категорий.

JavaScript реально загружает CSV через `fetch()`, проверяет поля, создаёт HTML-карточки и фильтрует их без перезагрузки страницы.

## Запуск после клонирования
1. Установить Node.js (с npm). Требуется Интернет для первой установки Sass.
2. В корневой папке проекта выполнить:

   ```bash
   npm install
   npm run build:css
   ```

3. Открыть `index.html` через **Live Server** в VS Code. Альтернатива: при установленном Python выполнить `python -m http.server 5500` в корневой папке и открыть `http://localhost:5500`.

Не открывайте HTML простым двойным щелчком (через `file://`), иначе браузер может заблокировать `fetch()` локального CSV.

### Команды SCSS
- Разовая сборка: `npm run build:css`
- Автоматическая пересборка: `npm run watch:css`
- Прямой эквивалент: `npx sass --no-source-map scss/styles.scss css/styles.css`

Готовый `css/styles.css` включён в проект, поэтому при обычном запуске Live Server предварительная установка Sass не обязательна. Для демонстрации пересборки преподавателю выполните команды выше.

## Структура
- `index.html` — семантическая HTML-разметка.
- `data/catalog.js` — загрузка CSV, создание карточек, фильтры, сортировка и обработка ошибок.
- `scss/_variables.scss` — тема из JSON и дополнительные размеры.
- `scss/_mixins.scss` — повторяемые наборы стилей.
- `scss/_base.scss` — базовые стили.
- `scss/_layout.scss` — Grid/Flexbox и медиазапросы.
- `scss/_components.scss` — карточки, поля, кнопка, состояния.
- `scss/styles.scss` — главный файл Sass.
- `css/styles.css` — CSS для браузера.
- `dataset/` — исходные данные преподавателя.
- `images/` — место для дополнительных изображений (при необходимости).

## Использование SCSS
- **SCSS-переменная** вычисляется при сборке и заменяется значением в CSS; **CSS custom property** (`--name`) остаётся в готовом CSS и может изменяться в браузере.
- **Partial-файлы** с `_` разбивают исходники по ответственности и подключаются из главного файла через `@use`.
- **Mixin** `panel` используется для боковой панели, карточек и информационного блока; `focus-ring` — для полей и кнопки.
- **Вычисление Sass:** `math.div(v.$space, 2)` даёт половину базового отступа (8 px).
- **Вложенность:** стили BEM-компонентов `&__title`, `&__body` и псевдокласса `&:hover`, не глубже трёх уровней.
- **Адаптивность:** breakpoint 980 px переносит фильтры над сеткой, breakpoint 600 px делает одну колонку. На 375 / 768 / 1440 px сетка рассчитана на 1 / 2 / 3 колонки соответственно.

## Сценарий проверки
1. Открыть страницу: видны 18 карточек из CSV с изображениями, ценами и рейтингами.
2. Выбрать категорию «Книги»: остаются 6 товаров. Нажать «Сбросить фильтры» — снова 18.
3. Ввести в поиск `товар 5`: останется один товар; ввести `несуществующий` — появится сообщение «товары не найдены».
4. Изменить сортировку — цены или рейтинг переставляют карточки.
5. В DevTools включить Responsive Mode, проверить ширины 375, 768 и 1440 px и отсутствие горизонтальной прокрутки.
6. Для проверки ошибки временно переименовать `dataset/catalog.csv`, обновить страницу — появится сообщение о невозможности загрузки; затем вернуть исходное имя.
7. Изменить, например, `$radius` в `scss/_variables.scss`, выполнить `npm run build:css`, обновить страницу и проверить новое скругление всех панелей/карточек.

## Вопросы на защиту
- **Откуда данные?** Из `dataset/catalog.csv`; тема задаётся значениями `dataset/theme.json` в SCSS-переменных.
- **Где превращение данных в интерфейс?** `loadCatalog()` → `parseCSV()` → `applyFilters()` → `renderProducts()` → `createCard()` в `data/catalog.js`.
- **Как обрабатывается ошибка?** `try/catch` ловит ошибку `fetch`/неверного CSV и вызывает `showMessage()`; пустой результат фильтра тоже имеет сообщение.
- **Почему Grid и Flexbox?** Grid отвечает за колонки страницы и сетку товаров, Flexbox — за внутренние элементы панелей и карточек.
- **Что делает JavaScript?** Загружает CSV и обновляет DOM и фильтры; Bootstrap JavaScript в работе не используется.
